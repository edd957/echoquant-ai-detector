# Data Card

## Dataset

The project uses synthetic transaction data generated by `sentinel_ai.data.synthetic`.

## Why Synthetic Data

Synthetic data makes the repository safe to publish publicly while still demonstrating realistic ML engineering patterns:

- No personal data.
- No regulated financial records.
- Reproducible distributions.
- Configurable drift for monitoring demos.

## Columns

- `amount`
- `customer_age`
- `account_age_days`
- `merchant_risk_score`
- `country_risk_score`
- `hour_of_day`
- `device_trust_score`
- `failed_login_count`
- `is_cross_border`
- `is_new_device`
- `is_high_risk`

## Known Biases

The data generation process encodes assumptions about risk that may not match real populations or financial systems. Any production adaptation must replace synthetic data with approved business data and governance-reviewed labels.
