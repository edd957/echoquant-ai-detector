# Security Policy

## Supported Versions

This is an initial public reference project. Security reports should target the latest version on the default branch.

## Reporting a Vulnerability

Please open a private security advisory if the repository is hosted on GitHub, or contact the maintainer directly.

Do not include real customer data, credentials, API keys, or regulated financial records in reports or reproduction cases.

## Data Handling

The repository uses synthetic data only. Production adaptations must apply organization-specific privacy, security, compliance, and access-control requirements.
